# Horsera visual reference

Reference inspected: <https://ex-coders.com/html/horsera/index.html>.

The reference informed visual direction only: warm cream and espresso surfaces, restrained gold accents, Cinzel-like display type paired with a clean sans-serif, spacious image-led sections, circular/orbit geometry, clipped card corners, fine divider lines, and restrained hover/reveal motion.

No Horsera application code, logo, photographs, or downloaded page assets are used in this site. The implementation uses locally authored Astro/CSS/SVG, self-hosted fonts, Al-Ramk-owned images, and official Al-Ramk app screenshots. CSS motion honors `prefers-reduced-motion`; the site contains no client-side interaction scripts.
